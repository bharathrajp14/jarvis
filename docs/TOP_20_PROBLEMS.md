# BR JARVIS — TOP 20 ARCHITECTURAL & OPERATIONAL PROBLEMS

## 1. Executive Problem Ranking
Ranked by impact, severity, frequency, security implications, and maintenance cost.

| Rank | Problem Title | Severity | Root Cause | Files Affected | Recommended Remediation | Difficulty |
| :--- | :--- | :---: | :--- | :--- | :--- | :---: |
| **01** | **Fragmented Storage Stores** | HIGH | 8 separate SQLite/JSON databases across `.jarvis/`, `memory_db/`, and `workspace/` | `memory/canonical_db.py`, `memory/unified_memory.py`, `memory/contact_manager.py` | Migrate all relational tables into `.jarvis/jarvis_core.db` with WAL mode & single-writer lock | MEDIUM |
| **02** | **Oversized Intent Engine Monolith** | HIGH | 1,811 lines of regex rules and hardcoded application paths in a single module | `core/intent_engine.py` | Extract app mappings and keyword rules into JSON/YAML configuration tables | MEDIUM |
| **03** | **Duplicated Action & Tool Systems** | HIGH | 58 procedural scripts in `actions/` run in parallel with 63 declarative tools in `tools/` | `actions/*`, `tools/*`, `tools/legacy_actions_tools.py` | Migrate reusable actions into declarative tool schemas in `tools/` and external integrations into `connectors/` | HIGH |
| **04** | **Triplicate Model Execution Pipelines** | HIGH | Coexistence of `backends/`, `gateway/model_gateway.py`, and `router/smart_router.py` | `gateway/model_gateway.py`, `router/core.py`, `backends/*` | Standardize all LLM invocations through `gateway/model_gateway.py` with multi-key rotation | MEDIUM |
| **05** | **Monolithic UI Window Class** | MEDIUM | `ui/main_window.py` is 1,649 lines handling layout, event loop, DWM blur, audio visualizer, and networking | `ui/main_window.py`, `ui/widgets.py` | Split into focused controller classes (`AudioVisualizerController`, `ChatTimelineWidget`, `ThemeManager`) | HIGH |
| **06** | **Browser Cache Git Tracking** | MEDIUM | Chromium cache and first-party sets written to git-tracked `workspace/browser_user_data/` | `.gitignore`, `workspace/browser_user_data/` | Enforce `.gitignore` exclusion and purge binary cache from repository | LOW |
| **07** | **In-Process Code Execution without Complete Sandbox Isolation** | HIGH | `tools/sandbox_process.py` and `actions/cli_controller.py` rely on path checks without OS sandbox containerization | `tools/sandbox_process.py`, `security/path_policy.py` | Enforce strict process isolation with restricted token privileges and directory boundaries | HIGH |
| **08** | **Silent Exception Swallowing in Legacy Actions** | MEDIUM | 14 instances of `try: ... except Exception: pass` in legacy automation routines | `actions/game_updater.py`, `actions/desktop.py`, `actions/file_processor.py` | Replace bare excepts with structured logging and strongly-typed error propagation | LOW |
| **09** | **Live Browser Automation Test Gaps** | MEDIUM | Unit tests mock Playwright/CDP; live Chrome session attach is unverified in CI | `tests/unit/test_server_web.py`, `tools/browser_tools.py` | Add integration test harness verifying local CDP port attach | MEDIUM |
| **10** | **Duplicate Bootstrapper Paths** | MEDIUM | `start.py` had redundant bootstrapper instantiation logic duplicating `core/bootstrap.py` | `start.py`, `core/bootstrap.py` | Ensure `start.py` delegates 100% of runtime creation to `core/bootstrap.py::build_assistant_runtime()` | LOW |
| **11** | **Direct Action Invocations Bypassing Policy** | HIGH | Heuristic regex rules in `core/intent_engine.py` called `actions/open_app.py` directly without 6-tuple validation | `core/intent_engine.py`, `security/policy_engine.py` | Route all intent action side-effects through `security/policy_engine.py` | MEDIUM |
| **12** | **Oversized PDF Manipulation Tool** | LOW | `tools/pdf_tools.py` is 1,257 lines combining OCR, text parsing, form filling, and metadata redaction | `tools/pdf_tools.py` | Refactor into modular package (`tools/pdf/parser.py`, `tools/pdf/forms.py`, `tools/pdf/ocr.py`) | MEDIUM |
| **13** | **Unbounded Re-entrant Tool Loop Risk** | MEDIUM | LLM tool loop could theoretically recurse if model continues emitting tool calls | `orchestrator/core.py` | Enforce hard iteration cap `MAX_TOOL_ITERATIONS = 10` with watchdog recovery | LOW |
| **14** | **Legacy Documentation Drift** | LOW | Root markdown files refer to MK37/MK38 commands (`python main.py`, `python start.py --gui`) | `readme.md`, `DEVELOPER_WALKTHROUGH.md` | Modernize documentation to recommend `python brjarvis.py` and `python ui_mark.py` | LOW |
| **15** | **Standalone Dashboard Server Duplication** | MEDIUM | `dashboard/server.py` implements its own mini HTTP server instead of mounting on FastAPI `api/` | `dashboard/server.py`, `server.py` | Mount dashboard endpoints onto FastAPI router in `api/routes/dashboard.py` | MEDIUM |
| **16** | **Hardcoded Audio Device Indices** | LOW | Windows audio device indices (e.g. index 2 or 5) can shift when USB devices are replugged | `start.py`, `voice/stt.py`, `voice/tts.py` | Use device name fuzzy matching (e.g. "AirBass", "Realtek") instead of raw integer indices | LOW |
| **17** | **Large Skills Library Dynamic Loading Overhead** | LOW | 380+ markdown skill files in `skills/library/` scanned on startup | `skills/loader.py`, `skills/registry.py` | Build a cached index SQLite database (`.jarvis/skills_index.db`) for instant startup | MEDIUM |
| **18** | **Speculative Execution Engine Fragmentation** | LOW | Minimal stubs in `orchestrator/speculative.py` and `reasoning/speculative_engine.py` | `reasoning/speculative.py`, `orchestrator/speculative.py` | Consolidate into a single module `reasoning/speculative.py` | LOW |
| **19** | **Redteam Scanner Subsystem Isolation** | LOW | `redteam/` scanner tools operate in isolation without integration into the central tool registry | `redteam/*`, `tools/registry.py` | Register redteam capabilities as declarative tools under high-risk policy tier | LOW |
| **20** | **Temporary Workspace Files Accumulation** | LOW | Temporary markdown evaluation notes left in `workspace/` during previous debug sessions | `workspace/*.md` | Establish automated workspace cleanup routine in `core/workspace_engine.py` | LOW |
