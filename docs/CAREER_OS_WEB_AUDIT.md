# BR JARVIS MK40.2+ — Web UI Studio Audit

## 10-Subtab Career OS Dashboard (`web/index.html` & `web/app.js`)
1. **Overview & Profile**: Real-time profile completeness score and contact info.
2. **Resume Studio**: Live resume generation, tailoring diff viewer, and format exports.
3. **Template Gallery**: Visual grid of 10 modern typography and layout templates.
4. **Job Search & Matching**: Live query input, fit scoring badges, and direct application triggers.
5. **Applications CRM**: Full interactive data table with deterministic status badges, timeline viewer, and manual action prompts.
6. **Interviews & Calendar**: Scheduled rounds, dates, timezones, and direct meeting links.
7. **Offers & Packages**: Detailed offer terms, compensation breakdown, conditions, and human confirmation modal.
8. **Email Intelligence**: Real-time activity feed of classified recruitment messages.
9. **Analytics & Funnel**: Telemetry metrics, conversion charts, and learning insights.
10. **Settings & Synchronization**: Excel sync controls, email fetch window, and backup management.
