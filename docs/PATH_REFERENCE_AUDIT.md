# PATH REFERENCE AUDIT & RUNTIME CONTRACT

All subsystem paths are governed by `brjarvis.core.paths.PathManager`:
- `PROJECT_ROOT`: Authoritative repository root
- `SOURCE_ROOT`: `src/brjarvis`
- `RUNTIME_ROOT`: `runtime/`
- `LOG_ROOT`: `runtime/logs/`
- `STATE_ROOT`: `runtime/state/`
- `ARTIFACT_ROOT`: `runtime/artifacts/`
- `CAPTURE_ROOT`: `runtime/captures/`
- `REPORT_ROOT`: `runtime/reports/`
- `TEMP_ROOT`: `runtime/temporary/`
- `WORKSPACE_ROOT`: `workspace/`
