# 10. Submission Verification Pipeline Specification

## Evidence Verification Standards

BR JARVIS enforces the **Fail-Closed Verification Invariant**: No application is marked as `SUBMITTED` or `SUBMISSION_VERIFIED` without physical proof.

### Accepted Proof Formats:
1. **Confirmation ID**: Authoritative receipt string generated by ATS portal (e.g. `APP-849204`).
2. **Confirmation URL**: Terminal URL containing confirmation parameters (e.g. `.../jobs/49281/confirmation`).
3. **HTTP 200/201 API Receipt**: Valid JSON response payload from official platform API.
4. **Verified Confirmation Page Text**: Exact match of ATS success strings ("Thank you for applying").

Uncorroborated "clicks" or optimistic assumptions are rejected.
