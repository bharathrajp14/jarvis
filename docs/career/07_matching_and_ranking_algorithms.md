# 07. Matching and Ranking Algorithms Specification

## 10-Factor Transparent Matching Matrix

1. **Skills Match % (30%)**: Exact token and semantic overlap with candidate competencies.
2. **Experience & Seniority Fit % (20%)**: Experience depth and title seniority alignment.
3. **Education Fit % (10%)**: Degree level and academic specialization.
4. **Location & Remote Mode Fit % (15%)**: Alignment with candidate location and remote preferences.
5. **Role Title Affinity % (15%)**: Overlap between target titles and job title.
6. **Company Preference % (10%)**: Inclusion in preferred/excluded company lists.

## Ranking Engine
Boosts positions offering transparent compensation, high remote flexibility, and official API integration for optimal candidate experience.
