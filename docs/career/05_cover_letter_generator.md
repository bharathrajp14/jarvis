# 05. Grounded Cover Letter Generator Specification

## Principles

1. **Fact-Grounded Narrative**: Strictly weaves verified accomplishments, real project metrics, and actual technology stacks into the narrative.
2. **Zero-Cliché Structure**: Avoids generic boilerplate, focusing directly on engineering value proposition, deterministic reliability, and company mission fit.
3. **Multi-Format Export**: Generates plain markdown text and formal vector PDF formatted with candidate contact headers.
