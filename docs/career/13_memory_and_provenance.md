# 13. Memory Integration and Provenance Specification

## UnifiedMemory Architecture Integration

Verified career facts integrate across the 7-tier memory system:
- **L0 (Scratchpad)**: Transient ATS evaluation tokens.
- **L3 (Vector RAG)**: Semantic vector embeddings of verified achievements and technical competencies for retrieval during interview preparation.
- **L4 (Persistent Memory)**: Structured canonical profile facts and preferences.
- **L6 (Experience Replay)**: Historical conversion patterns across resume variants and platforms.
