# 14. CLI, Voice, and Web Interfaces Specification

## CLI Slash Commands
- `/career [stats|onboard]`: Profile overview and onboarding gap analysis.
- `/resume [role|tailor]`: Create, tailor, and export verified resume formats.
- `/jobs <query>`: Search and match live positions across Greenhouse, Lever, and Ashby.
- `/apply <job_id>`: Prepare application package and open assisted browser flow.
- `/ats [role]`: Execute 7-factor deterministic ATS audit.

## Voice Commands
- "Jarvis, what's my ATS score?"
- "Jarvis, find remote AI Systems Engineer jobs."
- "Jarvis, generate my master resume."
- "Jarvis, give me my career pipeline summary."

## Web Dashboard
- Career OS Studio integrated in dashboard navigation with real-time ATS gauge, live job search matching cards, and pipeline tracking grid.
