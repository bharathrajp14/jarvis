# 16 — USER INTERFACE & VISUAL DESIGN FORENSIC RECORD

## 1. Overview & Frontend Architecture
BR JARVIS includes three frontend interfaces:
1. **Desktop Native GUI** (`ui/`, `ui_mark.py`): PySide6 / Qt6 Cyberpunk frosted-glass interface with live animated audio waveforms, glowing HUD panels, multi-task tracking tabs, and holographic status indicators.
2. **Floating Desktop HUD** (`float_widget.py`, 25,134 bytes): Lightweight, always-on-top, draggable cyberpunk pill widget for quick voice/text interactions.
3. **Web Dashboard** (`dashboard/`, `web/`, `api/`): Web-based real-time telemetry dashboard with WebSocket streaming.

## 2. File-by-File Forensic Analysis

### `ui/main_window.py` (1,649 lines)
- **Role**: Primary Desktop UI Window (`MainWindow`).
- **Features**:
  - Frosted glass background using Windows DWM acrylic blur API (`_qt.py`).
  - Live FFT frequency visualizer connected to `voice/assistant.py`.
  - Dynamic theme selector with real-time CSS palette hot-reloading (`ui/colors.py`).
  - Chat history timeline with markdown rendering, syntax highlighting, and artifact download buttons.
- **Disposition**: **KEEP + IMPROVE**.

### `ui/widgets.py` (997 lines) & `ui/overlays.py` (739 lines)
- **Widgets**: `HudCanvas` (custom 2D QPainter canvas), `HardwareMetricGauge` (GPU/CPU/RAM circular dials), `TaskTrackerTree`.
- **Overlays**: `SetupOverlay` (First-run wizard), `HueWheel` (Cyberpunk color picker).
- **Disposition**: **KEEP**.

### `dashboard/server.py` (941 lines)
- **Role**: Legacy standalone HTTP dashboard server.
- **Flaw**: Implements its own mini HTTP server and custom JWT authentication rather than mounting onto FastAPI `api/`.
- **Disposition**: **REFACTOR & CONSOLIDATE** into `api/routes/`.
